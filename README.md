# crypto-storm-model

**코인 시장 폭풍 예보기** — 매 시간, 앞으로 24시간 안에 이 코인이 "평소보다 크게" 움직일 확률을 예보하고, 레버리지 과열 신호가 켜지면 특보를 더한다.

> 오를지 내릴지는 말하지 않는다. **얼마나 크게 움직일지**만 말한다.
> 위험 관리 도구이지, 매수·매도 신호가 아니다.

| **데이터** | 바이낸스 USDT 무기한 선물 32종목, 2023-11 ~ 2026-10, 1시간봉 (약 61만 시간) |
| **검증** | 규칙·합격 기준을 결과 보기 전에 등록 → 워크포워드 모의고사 1회 → 수능 1회 → 미래 데이터 실시간 기록 |

| **가장 위험한 순간** | 과열 + 이미 출렁이는 중 → 24시간 안에 **86%** 폭발 (모의고사 84.8%, 수능 86.0%) |

## 무엇을 예보하나

매 1시간봉이 끝날 때마다 묻는다.

> "앞으로 24시간 안에 가격이 **평소 하루 변동폭**만큼 위나 아래로 움직일까?"

- **평소 하루 변동폭** = 그 코인의 직전 14일 일봉 (고가 − 저가) 평균
- 고정 %(예: ±5%)를 쓰지 않은 이유: BTC의 5%와 신규 알트의 5%는 뜻이 다르다. 고정 %를 쓰면 모델이 신호가 아니라 "시끄러운 코인·시끄러운 해"를 외운다
- 결과: 폭발 비율이 연도·코인과 상관없이 약 24~26%로 일정 (고정 5%는 9~17%로 출렁임)

## 모델

| | 보는 것 | 방식 |
|---|---|---|
| **변동성 예보관** | 최근 4·24시간 움직임 폭 (평소 대비) | 로지스틱 회귀 |
| **폭풍 예보기 (최종)** | 위 + **과열 특보** | 로지스틱 회귀 |

**과열 특보 ("셋 다")** — 세 가지가 **동시에** 켜질 때
- 펀딩비 ≥ 0.02% (롱이 웃돈을 내며 몰림)
- RSI(14) ≥ 70 (가격 과열)
- OI가 1시간 전보다 증가 (레버리지 유입)

비유: 일반 일기예보 + 태풍 특보. 특보는 전체 시간의 약 0.3%에만 켜지지만, 켜질 때는 평소의 2.4배 잘 터진다.

## 검증 설계

과최적화(기출 암기)와 누수(시험지 미리 보기)를 막는 데 가장 많은 시간을 썼다.

| 장치 | 내용 |
|---|---|
| **사전 등록** | 모든 가설·합격 기준을 결과를 보기 전에 노트에 기록. 결과를 본 뒤 기준을 바꾸지 않음 |
| **워크포워드** | 모의고사: 2023-11 ~ 2024-10 공부 → 2024-11 ~ 2025-10 시험 / 수능: 2023-11 ~ 2025-10 공부 → 2025-11 ~ 2026-10 시험 (각 1회) |
| **비움 (엠바고)** | 공부 마지막 문제의 정답 창(24시간)이 시험 시작 전에 끝나도록 경계에 25시간을 비움 |
| **누수 방지** | 모든 힌트는 봉 마감 시각까지 나온 정보만 사용. 펀딩비·OI는 "그 시각 이전 마지막 값"만 |
| **진짜 상대** | 찍기가 아니라 **변동성 예보관**을 이겨야 합격. "최근 많이 움직였으면 또 움직인다"는 누구나 아는 사실이라, 그걸 이겨야 새 정보 |
| **점수 흔들림** | 1시간 문제끼리 정답이 23시간 겹침 → 시간이 아니라 **날 단위로 묶어** 부트스트랩 (500회) |
| **변경 횟수 기록** | 모의고사를 보고 공부법을 바꾼 횟수를 세고 제한 (3회 후 중단) |
| **코드 점검** | 모든 판정 코드는 "효과가 있는 가짜 데이터"에서 통과, "효과가 없는 가짜 데이터"에서 불합격하는지 먼저 확인 |

**채점**
- **AUC**: 위험한 순간을 위에 줄 세우는가 (0.5 = 동전)
- **Brier / 향상도**: 확률 숫자가 실제와 맞는가 (찍기 대비 개선 %)
- **정직함 검사**: "40%"라고 한 순간들이 실제로 약 40% 터졌는가

## 결과

### 1. AI가 스스로 조합하게 했을 때 — 실패 (연구 07)

32종목 모의고사, 상대 = 변동성 예보관 (AUC 0.687)

| 시도 | 내용 | AUC | 판정 |
|---|---|---|---|
| 로지스틱 | 힌트 6개 (변동성 + RSI + 펀딩비 + OI) | 0.679 | 불합격 |
| 트리 (부스팅) | 같은 힌트, 조합을 배울 수 있는 모델 | 0.686 | 불합격 (레버리지 힌트 중요도 ≈ 0) |
| 로지스틱 + 펀딩비 가공 | 펀딩비를 코인별 평소 대비로 | 0.675 | 불합격 |

- 손해는 주로 **공부 때 없던 신규 코인**에서 났다 (변동성 0.716 vs 로지스틱 0.683)
- 펀딩비를 평소 대비로 바꿔도 안 줄었다 → "날것 펀딩비가 범인" 가설 기각
- BTC 단독에서는 로지스틱이 간신히 합격했지만(AUC 범위 아래 끝 +0.000), 방향 힌트를 넣은 거의 같은 모델은 불합격 → **칼날 위의 합격**은 믿지 않기로 함

**배운 것**: 레버리지 정보는 드문 극단 순간에 몰려 있다. 그래서 모든 시간을 평균 내는 점수에서는 묻힌다. 그리고 "셋 다"는 AND 조건이라 로지스틱은 못 만들고, 트리는 데이터가 모자라 못 찾았다.

### 2. 과열 조합을 사람이 넣어줬을 때 — 통과 (연구 08)

새 가설로 등록하고, 채점을 **특보 순간**에 맞춰 다시 설계했다.

- ① 핵심: 특보가 켜진 시간만 놓고, 변동성 예보관보다 확률이 실제에 더 가까운가 (Brier 개선, 95% 범위 > 0)
- ② 안전장치: 전체 시간 점수가 나빠지지 않았나 (향상도 차이 95% 범위 > −0.5%p)

| | 모의고사 | **수능** |
|---|---|---|
| 특보 시간 / 날 / 코인 | 552 / 95 / 28 | **1,218 / 236 / 16** |
| 특보 순간 실제 폭발 | 63.0% | **64.8%** |
| 변동성 예보관 | 48.6% | 54.9% |
| **폭풍 예보기** | 57.6% | **63.7%** |
| ① Brier 개선 (95% 범위) | +0.020 (+0.005 ~ +0.034) ✓ | **+0.013 (+0.004 ~ +0.022) ✓** |
| ② 전체 향상도 차이 | +0.01%p ✓ | +0.03%p ✓ |
| 특보 + 변동성 낮음 → 실제 | 41.3% | 43.5% |
| 특보 + 변동성 높음 → 실제 | 84.8% | **86.0%** |

처음 보는 기간에서 숫자가 거의 그대로 재현됐다.

### 3. 실시간 확인 — 진행 중

수능 기간도 이전 연구들이 다른 질문으로 본 적이 있어서 100% 깨끗하지는 않다. 그래서 **2026-11-15부터** 얼린 모델로 매일 예보를 기록하고 있다 (바이낸스 공식 API, 작업 스케줄러 자동 실행). 특보가 100시간·20일 넘게 쌓이면 같은 기준으로 한 번 채점한다. 결과는 여기에 그대로 추가한다.

## 한계

- **수익 전략이 아니다.** 언제 조심할지 알려줄 뿐, 그 자체로 돈을 벌지 않는다. 지켜줄 수익 전략이 따로 있어야 의미가 있다
- **특보는 주로 신규 알트에서 켜진다.** 수능 특보 16코인 대부분이 2025년 이후 상장 코인. BTC·ETH에서는 펀딩비 0.02%에 거의 닿지 않아 특보가 안 켜진다
- **과열 문턱이 고정 숫자다** (펀딩비 0.02%). 시장이 차분해지면 입을 닫는다. 이전 연구 규칙을 그대로 쓰기 위해 일부러 고치지 않았다
- **종목 선정 편향**: "현재" 거래대금 상위 코인을 과거에 적용했다
- **방향은 모른다.** 이전 연구(01~03)에서 폭발 방향 예측은 10번 가까이 실패했다

## 연구 흐름

이 저장소는 "금융시장도 결국 사람들의 심리로 움직인다"는 질문에서 시작한 연구 시리즈의 일부다.

- **01~03** 과열 심리: 롱 과열(펀딩비 + RSI + OI)은 평소보다 약 1.5배 잘 터진다. 방향은 반반 → 방향 탐색 종료
- **02** 펀딩비 캐리: 진짜 엣지지만 자본 대비 연 약 3% → 무위험 이자 수준
- **04** 전일 고저점 돌파 ([crypto-daily-level-breakout](https://github.com/betteryou0315-glitch/crypto-daily-level-breakout)): 효과는 재현됐지만 수수료를 못 이김
- **05~06** 공포의 끝: 처음 데이터에서 통과, 처음 보는 코인에서 정확히 0 → 기각
- **07~08** 이 저장소

세 가지 원칙을 매번 확인했다.
1. 심리의 극단은 **크게 움직이는 건** 알려주지만, **어느 쪽인지는** 알려주지 않는다
2. 효과가 있다고 해서 **돈이 되는 건** 아니다
3. 처음부터 좋아 보이면 **일단 의심**한다
